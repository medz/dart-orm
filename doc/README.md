# Documentation

Start with the [quickstart](../README.md#get-started), then choose the guide for
the part of your application you are building.

| Task | Guide |
| --- | --- |
| Declare models, keys and relations | [Authoring](authoring.md) |
| Understand imports and execution | [API and mental model](api.md) |
| Filter, select, join and paginate | [Queries](queries.md) |
| Load related data | [Relationships](relations.md) |
| Work with domain values | [Types and codecs](types.md), [Decimals](decimals.md) |
| Define database behavior | [Defaults](defaults.md), [Computed columns](computed.md), [Checks](checks.md) |
| Evolve or adopt a database | [Migrations](migrations.md), [Backfills](backfills.md), [Importing](importing.md) |
| Use transactions, streaming and timeouts | [Execution](execution.md) |
| Subscribe to changes | [Query subscriptions](watch.md) |
| Inspect SQL and execution costs | [Observability](observability.md), [Performance](performance.md) |
| Use hand-written SQL | [Named SQL](named-sql.md) |
| Configure generation and project commands | [CLI](cli.md), [Generation](generation.md) |
| Build Flutter or browser applications | [Flutter](flutter.md), [SQLite Web](sqlite-web.md) |
| Use MySQL or MariaDB | [Drivers](mysql.md), [Migration recovery](mysql-migrations.md) |
| Check supported behavior | [Capabilities](capabilities.md), [Acceptance](acceptance.md) |
| Contribute or reproduce validation | [Contributing](contributing.md), [Progress](progress.md) |

The beta uses Dart declarations and engine-specific Dart migration histories.
The retired Prisma-based 5.x documentation does not describe this API.
